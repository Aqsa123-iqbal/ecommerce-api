# E-Commerce API — Enterprise RESTful + GraphQL (Lab 03)

## 📖 Introduction

This project is a modernized E-Commerce Platform API built with Node.js and Express.js. It provides RESTful product and order endpoints, standardized error handling, idempotent order processing, filtering, pagination, field selection, and GraphQL support.
